LiteRecorder — первый запуск

1. Распакуйте архив в удобную папку.
2. Дважды щёлкните по lite-recorder.exe.
3. Программа сама создаст на рабочем столе LiteRecorder-README.txt.

В созданном файле будет полный список команд с актуальным путём к программе.
Каждую команду оттуда можно целиком скопировать и вставить в командную строку.
Запуск без команды создаёт инструкцию; запись автоматически не начинается.

КАК ОТКРЫТЬ КОМАНДНУЮ СТРОКУ
1. Нажмите Win+R (клавиша Windows вместе с R).
2. Введите cmd и нажмите Enter.
3. Скопируйте нужную строку из LiteRecorder-README.txt на рабочем столе.
4. Вставьте её в открытое окно сочетанием Ctrl+V и нажмите Enter.

Если переместили EXE или обновили программу, запустите её ещё раз:
TXT на рабочем столе автоматически обновится с правильным путём и командами.
