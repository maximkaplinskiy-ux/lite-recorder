LiteRecorder — команды записи экрана

КАК ОТКРЫТЬ КОМАНДНУЮ СТРОКУ
1. Зажмите клавишу Windows и нажмите R (Win+R).
2. В появившемся окне «Выполнить» введите cmd.
3. Нажмите Enter. Откроется командная строка Windows (cmd.exe).
4. Скопируйте нужную строку ниже целиком, включая кавычки вокруг пути.
5. Вставьте её в командную строку сочетанием Ctrl+V и нажмите Enter.

Каждая команда ниже — одна отдельная строка. Переходить в папку программы
или вручную дописывать путь к EXE не нужно: программа уже подставила свой путь.
Эти команды предназначены для cmd.exe. Если открыли PowerShell, введите
в нём cmd и нажмите Enter, затем вставляйте команды из этого файла.

Этот TXT автоматически сформирован запущенной программой.
Путь к программе на этом компьютере:
{{EXE}}

НАЧАТЬ ЗАПИСЬ
"{{EXE}}" start

ОСТАНОВИТЬ ЗАПИСЬ И СОХРАНИТЬ ФАЙЛ
"{{EXE}}" stop

ЗАПИСАТЬ 30 СЕКУНД
"{{EXE}}" start --duration 30s

ЗАПИСАТЬ 5 МИНУТ
"{{EXE}}" start --duration 5m

ЗАПИСАТЬ 1 ЧАС
"{{EXE}}" start --duration 1h

ВЫБРАТЬ ПАПКУ ДЛЯ СЛЕДУЮЩИХ ЗАПИСЕЙ
"{{EXE}}" set-dir "D:\Записи"
В этой команде можно заменить D:\Записи на нужную папку.
Настройка сохраняется после закрытия программы и перезагрузки компьютера.

ПОКАЗАТЬ ТЕКУЩУЮ ПАПКУ СОХРАНЕНИЯ
"{{EXE}}" set-dir

ВЕРНУТЬ ПАПКУ СОХРАНЕНИЯ ПО УМОЛЧАНИЮ
"{{EXE}}" set-dir --reset

ЗАПИСАТЬ 2 МИНУТЫ В КОНКРЕТНЫЙ ФАЙЛ
"{{EXE}}" start --duration 120 --output "D:\Записи\урок.mp4"
Можно заменить путь и имя файла. Существующий файл не перезаписывается.

ПРОВЕРИТЬ, ИДЁТ ЛИ ЗАПИСЬ
"{{EXE}}" status

ПОКАЗАТЬ АУДИОУСТРОЙСТВА И ВЫБРАННЫЙ МИКРОФОН
"{{EXE}}" devices

ПОКАЗАТЬ ЭТУ СПРАВКУ
"{{EXE}}" help

ВКЛЮЧИТЬ БУФЕР ПОСЛЕДНИХ 5 МИНУТ
"{{EXE}}" replay-start 5
Замените 5 на нужное число минут. Можно указать 30s, 5m или 1h.

СОХРАНИТЬ ОТКАТ И ПРОДОЛЖИТЬ БУФЕРИЗАЦИЮ
"{{EXE}}" replay-save
Сохраняет последние X минут в отдельный MP4 в выбранную папку.
Если с запуска прошло меньше X минут, сохраняется накопленная часть.
Команда ждёт завершения сохранения; запись буфера при этом продолжается.

ВЫКЛЮЧИТЬ БУФЕР ОТКАТОВ
"{{EXE}}" replay-stop
Несохранённые фрагменты удаляются. Готовые откаты остаются.
Для сохранения перед выключением сначала выполните replay-save.

КРАТКО О РАБОТЕ
При первом запуске программа сама создаёт LiteRecorder-README.txt на рабочем столе.
После переноса EXE или обновления команд запустите программу ещё раз:
она автоматически обновит этот TXT, подставив актуальный путь.
Ручные изменения этого автоматически созданного файла могут быть заменены.
Запись работает в фоне: после команды start окно командной строки можно закрыть.
По умолчанию файлы сохраняются в системную папку Видео\LiteRecorder.
Таймер: целое число секунд (s или без суффикса), минут (m) или часов (h).
Текущую запись по таймеру также можно завершить командой stop.
Записывается основной монитор, системный звук и один микрофон.
Приоритет у обработанного микрофона (например, Voicemod), затем у обычного.
Если выбран Voicemod, запустите и настройте его до начала записи.
Выбор аудиоустройств выполняется при старте записи; проверяйте его командой devices.
Перед выключением компьютера завершайте запись командой stop.
Журнал последней записи: %LOCALAPPDATA%\LiteRecorder\last.log.
Строка FINISHED в журнале означает успешное сохранение видео.

Буфер и обычная запись включаются по очереди: перед сменой режима остановите текущий.
Для буфера действуют те же настройки экрана и выбора микрофона.
Буфер хранится на диске в %LOCALAPPDATA%\LiteRecorder\ReplayCache.
Фрагменты длиной около 5 секунд удаляются автоматически по мере устаревания.
На диске может быть до 5 лишних секунд, а также текущий и подготовленный фрагменты.
Ориентир объёма: до 46 МБ на минуту; сохранённые MP4 занимают дополнительное место.
Сохранение объединяет фрагменты средствами Windows и может занять время.
Журнал буфера: %LOCALAPPDATA%\LiteRecorder\replay.log.
При обычной остановке временные фрагменты удаляются. После аварийного завершения
они могут остаться в ReplayCache; удалять их вручную можно при выключенном буфере.
