# LiteRecorder — запись экрана и звука

Windows 10 (версия 2004 и новее) / Windows 11, x64. Программа на Rust без графического интерфейса, сервера и FFmpeg. Использует Windows Graphics Capture, WASAPI и системный кодировщик с аппаратным ускорением при поддержке драйвером.

## Команды

Откройте PowerShell в папке с `lite-recorder.exe`:

```powershell
.\lite-recorder.exe start
.\lite-recorder.exe stop
.\lite-recorder.exe start --duration 30s
.\lite-recorder.exe start --duration 5m
.\lite-recorder.exe start --duration 1h
.\lite-recorder.exe start --duration 120 --output "D:\Записи\урок.mp4"
.\lite-recorder.exe set-dir "D:\Записи"
.\lite-recorder.exe set-dir
.\lite-recorder.exe set-dir --reset
.\lite-recorder.exe status
.\lite-recorder.exe devices
.\lite-recorder.exe help
```

- `start` запускает запись в отдельном фоновом процессе; окно PowerShell можно закрыть.
- `stop` завершает запись и ждёт сохранения MP4. Запись по таймеру также можно остановить раньше.
- `--duration` задаёт целое число секунд (без суффикса или `s`), минут (`m`) или часов (`h`), от 1 секунды до 7 дней. Отсчёт начинается после первого кадра.
- `--output` задаёт путь к новому MP4. Существующие файлы не перезаписываются.
- `set-dir "D:\Записи"` сохраняет папку для всех следующих записей, в том числе после перезапуска программы и компьютера. Отсутствующая папка создаётся; перед сохранением настройки проверяется доступ на запись. Относительный путь считается от текущей папки PowerShell и сохраняется как абсолютный. Имена с пробелами заключайте в кавычки.
- `set-dir` без параметров показывает текущую папку; `set-dir --reset` возвращает «Видео → LiteRecorder». Изменение применяется к следующей записи; текущая продолжается в прежний файл. Параметр `start --output` имеет приоритет над сохранённой папкой для одной записи.
- `status` показывает, идёт ли запись. `devices` перечисляет активные аудиоустройства и отмечает выбранный микрофон и пропущенные каналы.
- Без аргументов выводится справка. При первом запуске программа генерирует на рабочем столе `LiteRecorder-README.txt`: обычный текст с инструкцией открытия cmd.exe и готовыми командами с полным путём к запущенному EXE. Каждую строку можно целиком скопировать и выполнить из любой папки. При изменении пути или команд TXT автоматически обновляется при следующем запуске. В архиве находится только инструкция первого запуска, не содержащая путей с компьютера сборки; шаблон полной справки встроен в EXE из `src/readme_template.txt`.

## Буфер откатов

`replay-start 5` включает хранение последних 5 минут на диске. Число без суффикса означает минуты; также доступны `30s`, `5m`, `1h` (от 1 секунды до 24 часов). `replay-save` сохраняет накопленный хвост в новый `replay-….mp4` в выбранной через `set-dir` папке и продолжает буферизацию. Если накоплено меньше времени, сохраняется доступная часть. `replay-stop` выключает буфер и удаляет временные фрагменты, сохраняя готовые откаты. Обычная команда `stop` также выключает текущий режим. Обычная запись и буфер не работают одновременно.

Временные файлы: `%LOCALAPPDATA%\LiteRecorder\ReplayCache`. Сжатые фрагменты имеют длину около 5 секунд; старый фрагмент удаляется, когда целиком выходит за окно. Нужен запас диска на X минут плюс несколько секунд, подготовленный фрагмент и сохранённые видео. При экспорте временно удерживается снимок выбранных фрагментов. Экспорт выполняется средствами Windows, обрезает начало до X минут и может требовать дополнительного времени и ресурсов. При штатной остановке кеш текущего сеанса удаляется; после сбоя питания или принудительного завершения он может остаться. Включение буфера автоматически после входа в Windows не выполняется.

## Экран и звук

Основной монитор с курсором в исходном разрешении, до 30 кадров/с; H.264, 6 Мбит/с. Системный звук и один автоматически выбранный микрофон смешиваются в одну стереодорожку AAC, 48 kHz, 160 кбит/с. Тишина сохраняется; моменты аудиопакетов привязаны к часам захвата экрана.

Порядок выбора микрофона:

1. Обработанный микрофон: Voicemod, MagicMic, MorphVOX, Clownfish, Voice.ai, VoiceWave, RVC, NVIDIA Broadcast/RTX Voice, Krisp, Sonar Microphone и устройства с названием «Virtual Microphone» / «Voice Changer».
2. Обычный микрофон или микрофон гарнитуры.
3. Неопознанный вход, назначенный микрофоном по умолчанию в Windows.

Среди устройств одной категории приоритет у устройства связи по умолчанию, затем у обычного устройства по умолчанию. Выбирается ровно один вход; при отсутствии подходящего микрофона записывается только системный звук. Stereo Mix, линейные входы, XSplit Broadcaster, кабели и шины микшеров исключаются. Виртуальные выходы маршрутизации Voicemod, XSplit, Voicemeeter и VB-Audio также исключаются из системного звука, чтобы повторно не добавлять исходный микрофон. Обычные наушники и динамики записываются.

Выбор основан на названиях устройств и настройках Windows, а не на анализе голоса. Переименованный или неизвестный виртуальный драйвер может определиться неточно; проверьте выбор через `devices`. Наличие установленной программы без её активного аудиоустройства не учитывается. Тишина в выбранном обработанном микрофоне не вызывает переключение на физический: запустите программу обработки и настройте её вход перед записью.

Устройства выбираются при старте. После подключения нового микрофона, переключения наушников или изменения разрешения экрана остановите запись и запустите заново. При недоступности любого выбранного устройства программа сообщает об ошибке, а не молча исключает источник. Разрешите доступ к микрофону для классических приложений в параметрах Windows.

«Прослушивание» микрофона через записываемые наушники или динамики всё ещё может дублировать голос; эхоподавления нет. Очень громкая сумма ограничивается, возможны искажения. Защищённое видео и звук, эксклюзивный вывод звука, отключённые устройства и звук из другой пользовательской сессии могут быть недоступны. Экран должен оставаться разблокированным. Смена рабочего стола, отключение дисплея или устройства могут прервать запись.

## Файлы и диагностика

Изначально видео сохраняется в системную папку «Видео» → `LiteRecorder`. Изменить папку можно командой `set-dir`; настройка хранится в `%LOCALAPPDATA%\LiteRecorder\output-dir.txt`. Около 46 МБ на минуту при указанном битрейте; фактический размер зависит от кодировщика. Журнал последнего запуска: `%LOCALAPPDATA%\LiteRecorder\last.log`. Строка `FINISHED` означает успешное закрытие файла. После записи по таймеру проверьте этот журнал, если видео не появилось.

Запись не запускается автоматически при входе в Windows. Во время записи работает один фоновый процесс; после остановки он завершается. Не завершайте его через диспетчер задач: незакрытый MP4 может не воспроизводиться. Используйте `stop` перед выключением компьютера. Программа не восстанавливает MP4 после сбоя питания.

## Сборка из исходников

Нужны Rust MSVC и Visual Studio Build Tools с Windows SDK:

```powershell
cargo build --release
cargo test
cargo clippy --all-targets -- -D warnings
```

Результат: `target\release\lite-recorder.exe`. Для переноса достаточно EXE и системных медиакомпонентов Windows. В редакциях Windows N может потребоваться Media Feature Pack. Исходники используют библиотеки `windows-capture` (MIT), `wasapi` (MIT) и `windows` (MIT/Apache-2.0).
